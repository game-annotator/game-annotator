When to use which algorithm

  • Full Extraction — You need every meaningful frame. Set FPS to match game pace (1 for turn-based, higher for real-time).
  • Uniform Sampling — You want reliable coverage of the whole video with a fixed budget of frames. Frames are evenly spaced, so nothing is missed.
  • Random Sampling — You want variety for training data or quick spot-checks. Frames are random so each run gives a different set.
